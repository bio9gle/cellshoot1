🧬 세포소기관 슈팅 아카데미

병원체를 물리치고 미지의 세포소기관 카드를 모아라!
퀴즈를 맞히면 연료가 보충되지만, 비행선에 맞는 소기관만 연료로 쓸 수 있다.

동물세포 비행선

연료: 동물세포 소기관 + 공통 소기관
(리소좀, 중심체 등은 OK / 엽록체·세포벽·액포는 ✗)

식물세포 비행선

연료: 식물세포 소기관 + 공통 소기관
(엽록체, 세포벽, 액포 등은 OK / 리소좀·중심체는 ✗)

조작 ← → (또는 A/D) 이동, ↑ ↓ (W/S) 전·후진, 스페이스 발사 · 모바일은 화면 버튼
규칙 연료는 계속 줄어든다. 병원체를 일정 수 격파하면 중간 보스가 등장하고, 보스를 물리치면 ? 카드가 떨어진다. 카드를 먹으면 소기관이 공개되며 퀴즈가 나온다. 정답 + 비행선에 맞는 소기관 = 연료 +45 · 정답이지만 맞지 않는 소기관 = 점수만 · 오답 = 연료 −10
적과 충돌하거나 보스 탄에 맞으면 연료가 줄어든다. 연료가 0이 되면 게임 오버!
